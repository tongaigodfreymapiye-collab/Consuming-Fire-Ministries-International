Church administrator setup

This website is hosted on GitHub Pages, which cannot securely store passwords or accept shared posts by itself. To enable real accounts and shared submissions, create a Supabase project, put its project URL and public anon key in supabase-config.js, run supabase-testimonies-schema.sql in Supabase SQL Editor, and review pending posts in the Supabase dashboard. Never publish a service-role key.
