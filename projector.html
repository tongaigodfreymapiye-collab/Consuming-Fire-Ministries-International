Service order

Build the order of service and select an item to preview it. Items stay in this browser until exported.

    Preview / Live workflow: Select any library item to preview it here. Preview changes do not go live automatically. Click “Open live window” once, move it to your projector using Extended Display, then click “GO LIVE: send preview” only when ready. Prepare the next item in preview while the current live item remains on screen; click GO LIVE again to take the next item live.
    PowerPoint note: reliable live PowerPoint control requires Microsoft PowerPoint or a dedicated desktop integration. This browser-based starter supports local preview for images and common audio/video formats, PDF preview where the browser supports it, and service-order management. It does not claim to control the PowerPoint desktop application.
